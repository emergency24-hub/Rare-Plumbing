RARE Plumbing London website

Open index.html in a modern browser. No installation, server or build step is required.

To edit company details, service wording, areas and FAQs, open script.js and change the SITE block at the top. Images are in assets/. To change colours, edit the variables at the start of styles.css.

Service pages use local hash URLs, so they work when index.html is opened directly from a folder. The site does not send enquiries through a form; the call and email buttons use the visitor's phone or email app.

The site uses 07451268940, info@rareplumbing.uk and rareplumbing.uk from the explicitly labelled company details.
